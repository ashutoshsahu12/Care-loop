# Member 3 — Admin, Monitoring & Analytics

This directory contains the work for Member 3 of CARELOOP — Closing the Screening-to-Care Loop.

## Responsibilities

- Build the admin dashboard and key project metrics.
- Monitor screening and care cases, assignments, due dates, and activity.
- Track overdue referrals, missed appointments, unacknowledged notifications, and unresolved cases.
- Identify cases at risk of being lost to follow-up using transparent, rule-based indicators.
- Present analytics for referral completion, appointment attendance, notification acknowledgement, consultation timelines, and verified case closure.
- Integrate with the team's shared API and data schema, and test the end-to-end workflow.

## Development notes

- Coordinate API contracts and data definitions with the other team members.
- Use synthetic demonstration data only; never commit real patient or medical information.
- Follow the repository's existing framework and conventions.
